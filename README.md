# WindowReaper downloads

**Borderless fullscreen for any game.**
WindowReaper takes the borders off windowed games, fills the screen (taskbar included), remembers each game for next time and puts every window back when you're done.

This repo only hosts the Windows download. Get it from **[windowreaper.com](https://windowreaper.com)**, or directly (once the first release is out):

**[Download the latest WindowReaper for Windows](https://github.com/gravitysoftwaredev/windowreaper-download/releases/latest/download/WindowReaper-Setup.exe)**

Test builds aren't code-signed yet. If Windows says "Windows protected your PC", click **More info → Run anyway**.
